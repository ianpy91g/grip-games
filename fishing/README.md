# 釣魚大師（網頁版）

用 ORIORI 握力球釣魚：握緊、放鬆控制釣餌，魚上鉤時用力握把牠拉上來。魚越大，需要的握力越大。

**開始玩：** https://ianpy91g.github.io/grip-games/fishing/

## 玩法

1. **拋竿**：握緊再放開，放開前握越用力拋越遠。
2. **控制釣餌**：放鬆＝餌往下沉；握緊＝收線往船靠近（越用力收越快）。越深的地方魚越大：每種魚只追自己出沒深度附近的餌，餌沉過淺水區後小魚就不會追下來，深海大魚看得比較遠、也比較容易被吸引。餌沉到海底的水草叢會被勾住，要重新拋竿。
3. **咬餌**：魚會先輕咬幾下，這時要放鬆；太早用力會把魚嚇跑。等「！」出現，在時限內用力握（一般模式 8）就上鉤了。沒握到，魚會把餌吃掉，要重新拋竿。
4. **拉魚**：握力超過那條魚的門檻就能把魚拉近，不夠就會被拖走，拉近進度歸零就斷線。魚會不時**掙扎**（先閃 ⚠ 警告），掙扎時門檻變成 1.3 倍，要瞬間加力撐住。拉魚時計時暫停。
5. 一局 **90 秒**，比釣到的魚總重。每種魚第一次釣到會收進**圖鑑**。

## 難度（選單按鈕切換）

| 難度 | 握力倍率 | 「！」之後幾秒內要握 |
|---|---|---|
| 兒童 | ×0.6 | 1.4 秒 |
| 一般 | ×1.0 | 1.0 秒 |
| 困難 | ×1.25 | 0.8 秒 |

## 操作

- 選單按「連接握力球」，選擇 `weixin-` 開頭的裝置。
- 沒有握力球時，遊戲中按住畫面（或空白鍵）也能玩。
- 捏一下握力球＝按「下一步」（開始、繼續、再玩一次）。
- 鍵盤：Enter 下一步、Esc 回選單、M 音樂、K 切換難度、D 圖鑑。

## 存檔

localStorage key `fishingGame.v1`：難度、音樂開關、圖鑑（每種魚釣到幾條、最大重量）、各難度最佳總重。

## 檔案

- `fishing.js`：遊戲本體（畫圖、邏輯、音效、音樂），不碰 DOM，可在 Node 測試；開頭的 `VERSION` 顯示在選單右下角
- `app.js`：畫面縮放、觸控、Web Bluetooth（服務 `FFB0`、握力通道 `FFB2`）、存檔
- `index.html`：外殼，每次開啟用時間參數載入 js，避免 Bluefy 拿到快取舊版
